A [Akeba](https://www.akeba.com.br) é o marketplace de produtos criativos e artesanais feitos por
criadores independentes do Brasil. A API REST da Akeba permite que vendedores integrem seus sistemas
(ERPs, hubs de integração, automações próprias) para gerenciar a operação da loja de forma programática.

<CardGroup cols={2}>
  <Card title="Pedidos" icon="box" href="/guias/fluxo-de-pedidos">

    (aceitar, iniciar produção, enviar com rastreio, voltar para produção).
  </Card>
  <Card title="Produtos" icon="tag">
    Liste produtos com imagens, categoria e tags. Atualize preço base e
    preço promocional.
  </Card>
  <Card title="Estoque" icon="warehouse">
    Consulte e atualize quantidades por variação (SKU), com sincronização
    automática do estoque global.
  </Card>
  <Card title="Webhooks" icon="bolt" href="/guias/webhooks">
    Receba notificações em tempo real de pedidos pagos, mudanças de status
    e cancelamentos.
  </Card>
</CardGroup>

## URL base

```text
https://akeba.com.br/api/v1
```

Todas as respostas são em JSON (`Content-Type: application/json`). Todos os identificadores são UUIDs.

## Primeiros passos

<Steps>
  <Step title="Gere seu token">
    Acesse o [painel de integrações](https://akeba.com.br/vendedor/integracoes) e gere um token de API.
  </Step>
  <Step title="Teste a conexão">
    Chame `GET /ping` com o header `Authorization: Bearer SEU_TOKEN` — veja o [Quickstart](/quickstart).
  </Step>
  <Step title="Explore a referência">
    Consulte a aba **Referência da API** para ver todos os endpoints, parâmetros e exemplos de resposta.
  </Step>
</Steps>

  Está começando agora? Siga o [Quickstart](/quickstart) para fazer sua primeira
  chamada em menos de 5 minutos.
