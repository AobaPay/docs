Este guia leva você do zero à primeira chamada autenticada: gerar um token,
testar a conexão e listar seus pedidos.

## Pré-requisitos

- Uma conta de **vendedor** ativa na [Akeba](https://www.akeba.com.br)
- Uma ferramenta para fazer requisições HTTP (`curl`, Postman, Insomnia ou seu ERP)

## Comece agora

<Steps>
  <Step title="Gere seu token de API">
    Acesse o painel do vendedor em [**Integrações**](https://akeba.com.br/vendedor/integracoes)
    e clique em **Gerar token**.

    <Warning>
      O token é exibido **uma única vez** ao ser gerado. Guarde-o em local seguro.
      Tokens podem ser revogados a qualquer momento no painel de integrações.
    </Warning>
  </Step>
  <Step title="Teste a conexão">
    Chame o endpoint `GET /ping` enviando o token no header `Authorization`:

    ```bash
    curl https://akeba.com.br/api/v1/ping \
      -H "Authorization: Bearer SEU_TOKEN"
    ```

    Se tudo estiver certo, a resposta identifica a sua loja:

    ```json
    { "pong": true, "loja_id": "9d3f2c1a-..." }
    ```
  </Step>
  <Step title="Liste seus pedidos">
    Busque os itens de pedido pendentes de aceite:

    ```bash
    curl "https://akeba.com.br/api/v1/pedidos?status=pending" \
      -H "Authorization: Bearer SEU_TOKEN"
    ```
  </Step>
  <Step title="Aceite um item">
    Use os IDs retornados no passo anterior para aceitar um item e iniciar o
    [fluxo de entrega](/guias/fluxo-de-pedidos):

    ```bash
    curl -X POST \
      "https://akeba.com.br/api/v1/pedidos/{pedidoId}/itens/{itemId}/aceitar" \
      -H "Authorization: Bearer SEU_TOKEN"
    ```
  </Step>
</Steps>
